
# Rust Panel 🛠️

**Rust Panel** is a configurable Windows gameplay overlay designed around Rust's survival, combat, resource gathering, and base-building mechanics. It brings together player ESP, resource visualization, radar, recoil settings, container markers, and navigation tools in a unified interface. The panel organizes player awareness, ore nodes, loot containers, monuments, and building-related information into dedicated categories. Configurable hotkeys and visual filters provide convenient access to supported survival utility modules.
